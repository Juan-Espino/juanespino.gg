# Bloggin

A personal blog app for writing, editing, publishing, and sharing Markdown articles.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Better Auth
- Drizzle ORM
- UploadThing
- PostHog
- pnpm

## Deployment

Vercel

## Database

PostgreSQL, managed through Drizzle ORM.
